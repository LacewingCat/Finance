# 数据适配验收记录

执行日期：2026-11-01（北京时间，报告文件按 UTC 日期命名为 2026-10-31）。这里只保存方法、汇总数字和公开产品代码，逐条公共行情验证数据保存在仓库之外；没有写入用户持仓、交易或 API 密钥。

## 可重复运行

```sh
npm run test:contracts -- --quick
npm run test:contracts -- --full
```

默认输出为 `~/Library/Application Support/Finance/public-data-verification-YYYY-MM-DD-{quick|full}.json`，可用 `FINANCE_DATA_DIR` 指定其他仓库外目录。脚本拒绝仓库内部目录及解析后指向仓库的符号链接。每只产品结束后原子保存进度；同一 UTC 日期重跑可恢复并重试未取得有效观测或历史的产品。验证脚本不读取用户数据库或密钥。

`--quick` 验证全目录与六只参考基金。`--full` 按 12 家管理人的公开产品名称选择广样本，并额外纳入货币、ETF 和六只参考基金；报告独立列出混合、债券、货币、ETF、联接、QDII、FOF、LOF 类别覆盖。主来源失败不会从结果删除，备用来源使用情况及原始错误都会保留。

验收门槛：至少 120 个可读取价格/净值产品、12 家去重管理人、30 条有效历史序列、30 次同代码同估值日的独立监管净值比对。门槛通过不意味着每个类别都可实时交易，也不意味着所有样本数据齐全。CSRC 对照使用官方公开 HTTP 路径，传输信任低于 HTTPS，只作为独立核对证据，不把免费行情升级为可触发投资告警的数据。

## 广样本进展与限制

首轮只使用主销售页的 126 只广样本结果为：50 个最新净值、56 条历史、11 家管理人；独立官方对照尚未执行，**该轮未通过**。这揭示了销售页大量 404 及易方达自管产品历史路径差异，不能把“覆盖六只参考基金”外推为全市场覆盖。

已据此加入页面真实引用的自管历史路径和东方财富正式净值备用序列，并保留主来源错误、备用质量标记。恢复后的 **162 只混合样本已完成验收门槛**：156 个可读取价格/净值、156 条有效历史、17 家去重管理人、30 次同份额同日期 CSRC 正式净值比对一致，无未完成的门槛项。

这 156 个观测包含 **150 个正式单位净值与 6 个 ETF 成交价**。运行时质量仍分别为 66 个主来源 `valid`、84 个备用来源 `unverified`、6 个周末旧报价 `stale`；独立验收并未自动提高来源质量。六只货币基金没有取得满足规则的正式单位净值或历史，保持“数据不足”，不以收益率冒充价格。

类别允许重叠，例如同一产品可能同时为 QDII、FOF、LOF，因此不能把各行相加作为总产品数。FOF/LOF 的当前样本仍只有一只，不代表所有此类产品均可自动解析。ETF 历史列是每日基金单位净值，报价列来自二级市场成交；折溢价、估值时点和计价口径可能不同，不能把二者接成同一价格曲线或进行数值一致性验收。当前并未验证 ETF 每日成交价历史。

30 次有效官方对照均匹配。脚本还保留此前误选的 6 个 ETF 对照记录并标为 `not_applicable`，因为成交价不能与单位净值进行一致性比对；它们不计入 30 次通过数。最终证据位于此次指定的仓库外目录 `/private/tmp/finance-public-data-verification/`，完整 JSON 未进入 Git。
