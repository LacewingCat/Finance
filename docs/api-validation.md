## 边界与复现

[verify-api.ts](../scripts/verify-api.ts) 默认 dry-run，不读取 Key、不创建验证数据库、不联网。只有显式 `--live` 才进行付费阶段。当前版本的合成记录、提示词和请求审计仍写固定隔离目录；费用预留、结算、全局超额保护和探针请求归属写入生产共享预算。真实模式只读取生产月度上限、Credit 金额、确认状态与起止日期，不读取持仓、流水或整个设置对象，不修改生产 API 开关。模型请求只允许官方模型目录 GET、Responses POST 和 Decisions POST，不启用收费搜索。公开基金使用原有免费数据适配器。

```sh
npm run verify:api
```

真实模式仅在明确授权后使用：

```sh
npm run verify:api -- --live
```

已经尝试过的阶段会跳过。免费模型目录最多两次有界尝试：仅传输失败、5xx 或不超过 2 秒的 Retry-After 可再试一次，401/403 不重试。`--retry-free-failure` 仅允许恢复没有产生任何费用或预留的失败阶段。付费 POST 没有自动重试。独立契约阶段只验证合成协议，不代替默认 Prompt 验收。所有运行使用生产共享预算中的固定探针归属，历史未决预留计入显式选择的累计硬限，不能通过重启、跨月或新建隔离账本绕开。

本轮起初免费模型目录连接失败；一次独立免费 GET 后取得 HTTP 200，随后恢复未发出过付费请求的阶段。之后两次付费请求未获得可验证响应，原费用预留继续保留。只读诊断时域名仅解析出一个 IPv4 地址，两次无 Key GET 均返回预期的 401，不能证实 IPv6、DNS 或 Clash 是故障原因。

在另行明确授权最多两个新契约请求后，先免费验证连接，再用进程级 `--dns-result-order=ipv4first` 运行；这两条新请求使用新 ID，均成功。没有重试原先的不确定 POST。由于原失败没有更细的传输错误日志，其根因仍未确定，不能断言 IPv4 优先解决了问题。新增审计已区分 transport、HTTP、响应 JSON、响应结构及 usage 校验阶段，只保存安全错误类型/代码和 HTTP 状态，不保存上游错误正文或 Key。全过程使用正常 TLS 校验，没有关闭证书校验或修改系统网络设置。

原始 usage、请求编号和响应分类保存于仓库外的私有验证目录，导出的探针费用取自共享生产账本。旧版隔离账本的 23 条费用按原 ID 幂等迁入共享预算；已在生产结算的记录不会被旧版 ambiguous 覆盖，同一 ID 的请求身份或结算金额冲突会阻止继续调用。两条仍未核实的 ambiguous 保持预留，不能仅导入已结算金额。新请求不再依赖事后手工同步费用。公开仓库不包含 Key、账户资料、用户 Credit 配置或完整模型目录。

### 共享预算修复（v0.1.1）

上述真实验收发生在生产 API 尚未启用期间，费用随后按原 ID 导入生产。交付检查发现旧探针只读取 Credit 配置、独立计算费用；若以后与网站同时运行，双方可能各自通过预算检查。现由 [probe-budget.ts](../src/server/probe-budget.ts) 把两者的 `ai-budget` 与 `ai-budget-state` 路由至同一生产 SQLite。网站和探针所有已用、未决预留共同受实际月度上限、最高 $90、有效 Credit 和 $5 安全余量约束；探针额外受 `--max-usd` 的累计硬限约束，普通网站请求不会占用探针自身的累计额度。

新预留在 `BEGIN IMMEDIATE` 内再次读取最新生产预算字段，复用原预算准入规则，并同时写入探针归属。事务提交后才允许付费 POST；进程中断、隔离审计写入失败或费用响应不明都不会清除生产预留。共享超额保护只能被探针置为阻止状态，探针不能清除。生产服务可以保持运行，显式 `--live` 只授权本次探针，不会打开或改写生产自动调用开关。

此次修复仅以临时 SQLite、Mock 和 dry-run 验证，没有新增付费请求。回归覆盖两个独立连接共享月度/Credit 余量、读取配置后降低额度、并发准入使用同库事务、崩溃后预留存续、跨月累计上限、历史导入不重复与冲突回滚，以及合成账本不写入生产资产记录。

没有验证本轮未触发的 >90% 决策链、真实投资质量、自动交易或 ChatGPT 手机通知。没有为达到阈值而反复调用模型。

本轮选择累计 **$0.50** 的更低执行上限。脚本默认仍为 $0.20，`--max-usd` 参数最多允许 $20，且任何显式上限都不能覆盖实际月度上限、已确认 Credit 及 $5 安全余量的限制。本轮当时只读取生产 Credit 四个字段，在生产未启用的条件下使用隔离费用账本；当前共享预算版本增加读取实际月度上限，并将所有历史探针已用和 ambiguous 迁入生产同一预算域。公开仓库不保存实际配置，不读取持仓或交易。

npm run verify:api -- --extended --max-usd=0.50
